# Assignment 8 — Study Programme Server

A small information server for a fictional Web Development study programme.
Built with Node.js, Express 5 and plain HTML, CSS and JavaScript.

## Development plan

- Set up npm, ES modules and development scripts.
- Add text, JSON and redirect routes.
- Add request logging, counting and the 404 fallback.
- Serve a programme page with buttons for trying the API.
- Test the responses and document the experiments.

Installation instructions and testing evidence will be added as the project develops.
